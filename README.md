# python-start

大一开始的 Python 练习仓库，记录从零基础到能独立写小程序的完整过程。

## 文件说明

| 文件 | 内容 | 涉及知识点 |
| --- | --- | --- |
| `hello.py` | 第一个程序 | 输出 |
| `guess.py` | 猜数字游戏 | 循环、条件、随机数 |
| `score.py` | 成绩统计 | 函数、列表、字典 |
| `wordcount.py` | 词频统计 | 文件读写、异常处理 |
| `sample.txt` | 词频统计使用的样本文本 | — |

## 如何运行

需要 Python 3.10 或更高版本。在本目录下执行：

```bash
python guess.py
python score.py
python wordcount.py
